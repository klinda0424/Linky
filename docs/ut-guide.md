# 사용성 테스트(UT) 진행 가이드

프로토타입에 UT 모드가 내장되어 있다. 주소에 `?ut=1`이 있을 때만 켜지며, 일반 시연에는 영향이 없다.

## 시작하기

| 주소 | 설명 |
|---|---|
| `/?ut=1&p=P01` | 참가자 P01, 서사형 톤, 과제 1부터 시작 |
| `/?ut=1&p=P02&tone=numeric` | 수치형 톤 |
| `/?ut=1&p=P03&task=U7-1` | 특정 과제부터 시작 |

- `p`를 생략하면 접속할 때 참가자 번호가 자동으로 정해진다 (예: P4821).
- 온보딩은 건너뛰고 과제 시작 상태로 바로 진입한다. 홈 상단의 시점 드롭다운은 숨겨진다.
- 폰에서 Vercel 프리뷰 주소 뒤에 위 파라미터를 붙여 열면 된다.

## 과제 (핵심 시연 5개)

| 순서 | ID | 참가자에게 주는 상황 | 성공 기준 |
|---|---|---|---|
| 1 | U3-1 | 시험 스트레스로 옷을 여러 벌 샀다. 그중 에이블리 결제가 어떻게 기록됐는지 확인하고 옷장에 정리한다 | 지출 상세에서 "옷장에 넣기" |
| 2 | U5-2 | 지친 날 밤, 오늘 하루를 돌아본다 | 하루 리포트 마지막 제안에 "네"/"아니요" 선택 |
| 3 | U6-1 | 병원에 다녀왔고 앱에 알림이 떠 있다. 알아서 처리한다 | 건강 동의 모달에서 동의/거절 선택 |
| 4 | U7-1 | 친구들과 제주 항공권을 샀다. 앱에서 확인하고 처리한다 | 그룹 지출 제안에 "네"/"아니요" 선택 |
| 5 | U11-1 | 여행 한 달 뒤, 그때 산 옷이 뭐였는지 앱에서 찾는다 | 검색 결과 화면 도달 |

각 과제는 상황 카드 → "시작하기"(타이머 시작) → 수행 → 성공 시 난이도(1~5) 응답 → 다음 과제 순서로 진행된다. 참가자는 상황 카드의 "이 과제 그만하기"로 포기할 수 있다.

## 진행자 패널

- 열기: 키보드 `Alt + Shift + U`, 또는 상단의 과제 칩(예: `1/5 · U3-1`)을 1.5초 안에 5번 탭
- 기능: 과제 점프, 현재 과제 처음부터, 이벤트/요약 CSV 내려받기, 기록 삭제

## 자동 기록

서버 없이 브라우저(localStorage)에 저장된다. 같은 브라우저에서 이어서 쌓이며, 패널에서 CSV로 내려받는다.

| 이벤트 | 의미 |
|---|---|
| `tap` | 반응하는 버튼을 누름 |
| `dead` | 아직 동작이 없는 버튼을 누름 (화면에 "프로토타입에서 준비 중이에요" 안내) |
| `miss` | 반응하는 요소가 없는 곳을 누름 (시트 바깥 영역 포함) |
| `screen` | 화면 이동 (`탭:화면` 형식) |
| `milestone` / `complete` / `giveup` | 성공 지점 도달, 과제 완료, 포기 |
| `ease` | 난이도 응답 (1~5) |

- **이벤트 CSV**: 모든 이벤트와 과제 시작 후 경과 시간(ms)
- **요약 CSV**: 과제별 결과(성공/포기/미완료), 소요 시간(초), 탭·헛탭·준비 중 탭 횟수, 화면 수, 난이도

## 주의

- 참가자마다 브라우저를 바꾸거나, 테스트 후 CSV를 받고 기록을 삭제한 뒤 다음 참가자를 시작한다.
- `miss`에는 모달 바깥 탭도 포함되므로, 헛탭 수는 절대값보다 과제 간 비교로 해석한다.
- 이 모드는 서버로 아무것도 전송하지 않는다.
