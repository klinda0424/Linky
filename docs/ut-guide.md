# 사용성 테스트(UT) 진행 가이드 — 장면 S1~S7 기준

> 흐름과 화면 문구는 `docs/user-flows.md`를 기준으로 한다. 월 리포트(S7-1)는 만들지 않으므로 과제에서 뺀다.

## 달라진 점

- 예전 앱 안 UT 모드(`?ut=1`, 진행자 패널, CSV 자동 기록)는 개편 때 main에서 빠졌다. 옛 구조로 만든 PR #35는 UT 전용이며 머지하지 않는다.
- 그래서 지금은 **진행자가 직접 관찰하고 기록한다.** 아래 기록표를 복사해서 쓴다.

## 준비

| 항목 | 내용 |
|---|---|
| 기기 | 참가자 폰에서 Vercel 프리뷰 주소를 연다. 노트북이면 `pnpm dev` 후 브라우저를 375px 폭으로 맞춘다 |
| 데이터 | 전부 목업이다(주인공 김소연, 2026년 10~11월). 참가자의 실제 정보는 입력받지 않는다. 닉네임은 아무 값이나 넣게 한다 |
| 초기화 | 앱은 상태를 저장하지 않는다. **새로고침하면 온보딩 1단계부터 다시 시작**한다. 참가자마다 새로고침한다 |
| 역할 | 진행자 1명(상황 읽기·시간 재기), 기록자 1명(탭·멈춤·발화 기록) |
| 확인 | 시작 전 아래 "과제 준비 상태"에서 🔶·⬜ 과제가 쓸 수 있는 상태인지 확인한다 |

## 진행 순서

1. 안내: "앱을 평가하는 게 아니라 앱이 쉬운지 보는 자리예요. 생각나는 걸 소리 내어 말해 주세요."
2. 온보딩은 참가자가 직접 진행한다(과제 1이 온보딩 안에 있다).
3. 과제마다 상황 카드를 읽어 주고 "시작"이라고 말한 순간부터 시간을 잰다.
4. 참가자가 "다 했어요"라고 하거나 성공 지점에 닿으면 멈춘다. 3분이 넘거나 참가자가 원하면 포기로 기록하고 다음 과제로 간다.
5. 과제마다 난이도(1 매우 쉬움 ~ 5 매우 어려움)를 묻는다.
6. 도움 요청에는 "어디를 눌러 보고 싶으세요?"처럼 되묻고, 정답 위치는 알려 주지 않는다.

## 과제

| 순서 | 장면 | 참가자에게 주는 상황 | 성공 지점 | 관찰 포인트 |
|---|---|---|---|---|
| 1 | S1-2 | 사진은 꼭 필요한 것만 쓰게 하고 싶어요. 앱을 시작하면서 설정해 보세요 | 개인정보 고지에서 갤러리 사용 범위를 읽고 "동의하고 계속"(거절도 성공) | 사용 범위 문구("±30분 · 반경 500m")를 읽는지, "동의 안 함"을 찾는지, 거절 뒤 불안해하는지 |
| 2 | S1-3 | 카드 결제내역을 불러오려고 해요. 꼭 필요한 약관에만 동의하고 진행해 보세요 | 필수 3개만 체크(선택은 비움) → 불러온 결과에서 "새 결제 자동 불러오기 끔" | "전체 동의"부터 누르는지, (필수)/(선택) 표시를 읽는지, ⌄로 내용을 펼쳐 보는지 |
| 3 | S2-1·S2-3 | 10월에 내 기록으로 채우지 못한 날이 며칠인지 알려 주세요 | "4일"이라고 답하거나 회색 날짜를 짚음 | 5단계 결과와 캘린더 3상태(진한·옅은·회색)를 구분하는지 |
| 4 | S3-3 | 10월 12일 마르디 결제에 그날 안 간 곳 사진이 붙어 있어요. 고쳐 주세요 | 서울숲 사진만 "제외" 후 "맞아요" → "✓ 확인함" | "수정"을 찾는지, 사진 전체가 아니라 1장만 빼는지, "근거 N개로 다시 계산했어요"를 보는지 |
| 5 | S4-1~S4-3 | 10월 12일 점심은 지은·민지랑 같이 먹고 내가 냈어요. 내가 실제로 쓴 돈으로 정리해 주세요 | 반영 결과 "내 지출 11만"(하루)·"120만"(10월) 화면 | 카드 안 알림의 "맞아요"를 누르는지, 자동 입력된 3명을 믿는지, 결과 숫자를 이해하는지 |
| 6 | S5-2 | 10월 12일 밤 35,500원 결제가 뭐였는지 기억이 안 나요. 쇼핑몰 주문내역 캡처로 채워 주세요 | "블라우스 1벌, 맞나요?"에 답하고 10/12 셀이 진하게 바뀜 | "기록 없음" 카드의 "캡처·사진 추가"를 찾는지, 인식 결과를 확인하는지 |
| 7 | S6-1·S6-2 | 10월 12일에 어디를 다녔는지 지도로 보고, 옷 산 곳 결제를 열어 보세요 | 하루 동선 지도에서 결제 핀 → 결제 카드 | 핀의 "결제 당시 내 위치"를 **상점 위치로 오해하는지**, 사진 핀과 결제 핀을 구분하는지 |
| 8 | S7-2 | 다음 달(11월)에는 기록이 얼마나 채워졌는지 확인해 주세요 | 11월 화면에서 "26일 / 30일" 확인 | 월 이동 화살표를 찾는지, "지난달 N일"을 읽는지 |
| 9 | S7-3 | 10~11월에 성수에서 쓴 돈을 찾아보세요 | "성수에서 쓴 돈" 검색 결과 | 검색 진입점을 찾는지, 어떤 말로 검색하는지(그대로 기록) |

- **헛탭**: 반응하는 요소가 없는 곳을 누른 횟수. 시트 바깥을 눌러 시트가 닫힌 경우는 따로 적는다.
- **관찰 메모**: 멈춘 화면, 소리 내어 한 말(그대로), 잘못 이해한 문구.

## 마치고 묻는 질문

유도하지 않게 열린 질문으로 묻는다.

1. 결제 옆에 붙은 위치·일정·사진은 무엇이라고 생각했나요?
2. 지도의 결제 핀은 어디를 가리킨다고 생각했나요?
3. "기록 없음"이라고 적힌 결제를 봤을 때 어떤 느낌이었나요?
4. 사진·위치를 쓰는 범위를 설명한 화면에서 기억나는 게 있나요?
5. 이 앱에서 다시 쓰고 싶은 기능과 쓰고 싶지 않은 기능은요?

## 문구·규칙 점검 (진행 중 같이 본다)

- [ ] 지도 결제 핀이 "결제 당시 내 위치"로 이해되는가 (상점 위치로 오해하지 않는가)
- [ ] "기록 없음"을 오류로 받아들이지 않는가
- [ ] 앱이 기분·의도를 짐작한다고 느낀 문장이 있었는가 (있으면 문장을 그대로 적는다)
- [ ] 평가받는다고 느낀 문장이 있었는가
- [ ] 눌렀는데 아무 일도 없던 버튼이 있었는가 (있으면 화면과 위치를 적는다)

## 주의

- 참가자에게 실제 결제·사진·위치 정보를 요구하지 않는다. 화면에 보이는 정보는 모두 가상의 인물이다.
- 기록표와 녹음은 팀 공유 폴더에만 두고, 참가자 이름 대신 P번호를 쓴다.
- 과제 순서는 플로우 순서대로 둔다. 과제 4·5·6은 같은 날(10/12)을 쓰므로 앞 과제의 결과(사진 제외, 분할 확정)가 다음 과제 화면에 남는다.
