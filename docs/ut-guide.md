# 사용성 테스트(UT) 진행 가이드

프로토타입에 UT 모드가 내장되어 있다. 주소에 `?ut=1`이 있을 때만 켜지며, 일반 시연에는 영향이 없다.

## 시작하기

| 주소 | 설명 |
|---|---|
| `/?ut=1&p=P01` | 참가자 P01, 서사형 톤, 과제 1(U0-2)부터 시작 |
| `/?ut=1&p=P02&tone=numeric` | 수치형 톤 |
| `/?ut=1&p=P04&share=0` | 끝난 화면의 "기록 파일 받기" 버튼을 숨김 (진행자 기기 하나로 여러 참가자를 진행할 때) |
| `/?ut=1&p=P03&task=U0-2` | 특정 과제부터 시작 (`task=U0-2`, `U3-1`, `U5-1`, `U6-1`, `U7-1`, `U11-1`) |

- `p`를 생략하면 접속할 때 참가자 번호가 자동으로 정해진다 (예: P4821).
- 온보딩은 건너뛰고 과제 시작 상태로 바로 진입한다. 홈 상단의 시점 드롭다운은 숨겨진다.
- 폰에서 Vercel 프리뷰 주소 뒤에 위 파라미터를 붙여 열면 된다.

## 과제 (6개)

입력 과제 2개(U0-2, U5-1)로 **기록 1건 소요 시간**을 잰다. 서사형/수치형 톤 비교는 사후 인터뷰로 하므로 하루 리포트(U5-2)는 과제에서 뺐다 (화면·기능은 그대로 있다).

| 순서 | ID | 참가자에게 주는 상황 | 시작 시점 | 성공 기준 |
|---|---|---|---|---|
| 1 | U0-2 | 이번 학기 기말고사 일정을 앱에 등록하려고 해요. 학사일정 페이지 링크가 준비돼 있어요. | 여행 확정 (11/21), 일정 미등록 | 링크 업로드 → 인식 확인 "맞아요"(또는 수정 후 저장) → 캘린더에 '시험기간' 태그 생성 |
| 2 | U3-1 | 시험 스트레스로 에이블리에서 옷을 샀어요. 어떻게 기록됐는지 확인하고 정리해 주세요. | 시험기간 (12/12) | 지출 상세에서 "옷장에 넣기" |
| 3 | U5-1 | 지친 하루가 끝났어요. 오늘 기분을 남겨 주세요. | 시험기간 (12/12), 기분 미기록 | 기분 1개 선택 → 감정 보관함에 저장 |
| 4 | U6-1 | 병원에 다녀왔고 앱에 알림이 떠 있어요. 알아서 처리해 주세요. | 시험기간 (12/12) | 건강 동의 모달에서 동의/거절 선택 |
| 5 | U7-1 | 친구들과 제주 항공권을 샀어요. 앱에서 확인하고 처리해 주세요. | 여행 준비 (12/20) | 그룹 지출 제안에 "네"/"아니요" 선택 |
| 6 | U11-1 | 여행 한 달 뒤예요. 그때 산 옷이 뭐였는지 앱에서 찾아 주세요. | 한 달 뒤 (1/24) | 검색 결과 화면 도달 |

- U5-1의 기분 입력은 + 버튼의 "오늘 기분은요?" 이모지 또는 감정 보관함 카드로 할 수 있다 (AI 코치에는 기분 입력이 없다). 참가자가 어디로 들어가는지가 관찰 포인트다.
- 소요 시간은 "시작하기"를 누른 시점부터 성공 지점까지다. 입력 과제(U0-2, U5-1)의 소요 시간이 핵심 지표다.

각 과제는 상황 카드 → "시작하기"(타이머 시작) → 수행 → 성공 시 난이도(1~5) 응답 → 다음 과제 순서로 진행된다. 참가자는 상황 카드의 "이 과제 그만하기"로 포기할 수 있다.

## 진행자 패널

- 열기: 키보드 `Alt + Shift + U`, 또는 상단의 과제 칩(예: `1/6 · U0-2`)을 1.5초 안에 5번 탭
- 기능: 과제 점프, 현재 과제 처음부터, 이벤트/요약 CSV 내려받기, 기록 삭제

## 자동 기록

서버 없이 브라우저(localStorage)에 저장된다. 같은 브라우저에서 이어서 쌓이며, 패널에서 CSV로 내려받는다.

| 이벤트 | 의미 |
|---|---|
| `tap` | 반응하는 버튼을 누름 |
| `dead` | 아직 동작이 없는 버튼을 누름 (화면에 "프로토타입에서 준비 중이에요" 안내) |
| `miss` | 반응하는 요소가 없는 곳을 누름 (시트 바깥 영역 포함) |
| `screen` | 화면 이동 (`탭:화면` 형식) |
| `milestone` / `complete` / `giveup` | 성공 지점 도달, 과제 완료, 포기 |
| `ease` | 난이도 응답 (1~5) |

- **이벤트 CSV**: 모든 이벤트와 과제 시작 후 경과 시간(ms)
- **요약 CSV**: 과제별 결과(성공/포기/미완료), 소요 시간(초), 탭·헛탭·준비 중 탭 횟수, 화면 수, 난이도

## 주의

- 참가자마다 브라우저를 바꾸거나, 테스트 후 CSV를 받고 기록을 삭제한 뒤 다음 참가자를 시작한다.
- `miss`에는 모달 바깥 탭도 포함되므로, 헛탭 수는 절대값보다 과제 간 비교로 해석한다.
- 이 모드는 서버로 아무것도 전송하지 않는다.
