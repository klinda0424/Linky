## 0. 한 줄 정의

> **"기억 안 나는 지출을, 내가 이미 가진 기록으로 채워서 합리적 소비습관까지"**

- **서비스명:** Linky (링키) — 영문 표기는 대문자 L만
- **타깃:** 20대 여성
- **목적:** 20대 여성의 합리적 소비습관 만들기
- **차별점 한 문장:** 토스·뱅크샐러드는 "얼마 썼는지"를 보여주지만, Linky는 "왜 썼는지"를 복원해 "다음엔 어떻게 쓸지"까지 알려준다.

## 2. IA — 하단 탭 3개 + 상단 프로필 아이콘 (찐최종)

```
온보딩
 ├ 개인 정보
 ├ 서비스 권한 연동
 └ 지출 내역 분석
      │
 ┌────┴──────┬──────────────┐
캘린더        홈            리포트      ← 하단 탭 3개
(각 탭 상단 우측: 검색 · 프로필 아이콘 → 프로필 화면)
```

### 캘린더 탭 ← [일정] 소스
- 캘린더
- 일자별 지출 내역
- 검색
- 한 달 지출액

### 홈 탭
- 정산 알림 (필요시) → **정산 대기함**
  - 받아야 할 금액 / 정산표 / 완료된 정산
- 주간 캘린더
- 오늘 지출 → **지출 내역**
- 하루 리포트
- 오늘의 동선 지도 ← [위치] 소스
- 오늘의 사진 ← [사진] 소스
- 검색

### 리포트 탭 (독립 탭으로 승격)
- 주간 리포트
- 정산 내역 ← 정산 대기함에서 완료분 이동
- 내 지출 패턴
- 다음 주 예고
- 월간 리포트 (달에 한 번)
- 칭찬

### 프로필 (탭이 아니라 상단 우측 아이콘으로 진입하는 화면)
- 회원 정보 / 연동 서비스 관리 / 개인정보 & 권한 / 알림 설정

### 공통 — 지출 내역 상세
가맹점 결제 내역 · 결제 금액 · 결제 장소 · 그룹 결제 확인 알림 · 앨범에서 불러오기 · 하루 리포트

## 3. 핵심 기능 4개

### ① 지출 자동 수집
마이데이터 연동. 온보딩에서 한 번 연동하면 이후 **결제 기록 입력 0** — 기록 비용 제로

### ② 맥락 복원 ⭐
| 축 | 소스 | 결과 |
|---|---|---|
| 장소 | 위치 체류 + 사진 EXIF | "(주)포토이즘코리아" → **포토이즘 강남역점** |
| 이동 | 체류 구간 밖 결제 | "카카오모빌리티" → **압구정로데오역 2번출구 택시 탑승** |
| 맥락 | 캘린더 · 사진 내용 인식 | 그날의 일정·장면 연결 |

> 일반 통계·추측이 아니라 **사용자가 이미 가진 기록만** 사용
> ❌ 구매 항목(품목) 복원은 **범위에서 제외** — 영수증·주문내역 파싱 안 함

### ③ 정산(N빵) 자동 분리
- 내가 대표 결제 → "12만원 → 내 지출 3만원 / 받을 돈 9만원"
- 친구가 결제·내가 송금 → 맥락 없는 '이체'를 **사진 추론으로 식비 복원**

### ④ 리포트 — 복원에서 습관으로
주간 리포트 · 내 지출 패턴 · **다음 주 예고** · 칭찬 · 월간 리포트

## 4. Input → AI → Output 구조

### 4-1. 전체 흐름

```
INPUT                      AI                      OUTPUT
───────────────────────────────────────────────────────────────
금융(결제)  ┐                                   ┌ 홈 · 오늘 지출
금융(송금)  │          ① 장소 복원              │ 지출 내역 상세
위치(체류)  ├─ 타임라인 ─ ② 이동 복원 ─ 확인 ──┤ 오늘의 동선 지도
사진(EXIF+ │   통합      ③ 정산 분리   [맞아요 │ 오늘의 사진
   내용인식)│   인덱스    ④ 패턴·예고    /수정] │ 정산 대기함
캘린더(일정)┘                                   │ 리포트 탭
                                                └ 검색
```

### 4-2. INPUT — 5개 소스

| 소스 | 받는 데이터 | 수단 | 왜 필요한가 |
|---|---|---|---|
| 금융(결제) | 가맹점명 · 금액 · 승인시각 · MCC | 마이데이터 API | 모든 복원의 기준점 |
| 금융(송금) | 입출금 구분 · 금액 · 시각 · 적요(이름) | 마이데이터 API | 정산 역추적의 유일한 단서 |
| 위치 | 체류 좌표 + 진입/이탈 시각 | iOS Visit / Android Fused | "어디서" 복원 |
| 사진 | 촬영시각 · GPS + **내용 인식**(음식·장소·인원) | 사진 권한 + 온디바이스 비전 | "뭐 했는지" 추론 |
| 캘린더 | 제목 · 시간 · 장소 · 참석자 수 | EventKit / Google Calendar | "왜" 복원 + 미래 예고 |

**사용하지 않는 것:** 연락처, 이메일 영수증, 현금영수증, 앱 주문내역, 카카오톡 대화(API 없음)

### 4-3. 중간 레이어 — 타임라인 통합 인덱스

모든 데이터를 **시각(timestamp) 하나**로 줄 세운다. 시각이 겹치면 자동으로 같은 사건.

```
19:12  [위치] 연남동 체류 시작
19:40  [사진] IMG_3102 — 파스타, 2인 세팅, GPS 연남동
20:00  [일정] "지은이랑 저녁"
21:05  [위치] 체류 종료
21:30  [송금] "김지은" 앞 18,000원 출금   ← 가맹점 없음
```

### 4-4. AI 추론 엔진 4개

**① 장소 복원**
```
IN   가맹점명 + 승인시각 + MCC
     ├ 체류 구간 안 → 역지오코딩(카카오/네이버 로컬) → 반경 50m POI → 가맹점명 대조
     └ 사진 EXIF GPS 있으면 우선 적용
OUT  "(주)포토이즘코리아" → 포토이즘 강남역점 · 강남역 11번출구
```

**② 이동 복원**
```
IN   결제시각이 체류 구간 밖(= 이동 중) + 직전 체류지
OUT  "카카오모빌리티" → 압구정로데오역 2번출구 인근 택시 탑승
```

**③-A 정산 분리 (내가 대표 결제)**
```
IN   결제 1건 + 이후 72h 입금 내역
     ① 역송금 매칭  입금 N건, 각 금액 ≈ 총액/(N+1)   ★★★★★
     ② 객단가 배수  결제액 ÷ MCC 1인 평균            ★★★
     ③ 캘린더 참석자 수                              ★★★★
     ④ 사진 인원 수 (온디바이스 얼굴 검출)            ★★
     ⑤ 과거 같은 가맹점·멤버 조합 이력                ★★★★
OUT  총 12만원 → 내 몫 3만원 / 받을 돈 9만원
```
> ①은 추정이 아니라 **산술 역산** — "AI가 숫자를 지어내면 안 됨" 요구사항 정면 통과

**③-B 정산 분리 (친구가 결제, 내가 송금)** ⭐
```
IN   가맹점 없는 송금 1건 ("김지은 18,000원")
     ↓ 일정 동석자 대조 → 송금 적요 "김지은" ↔ 일정 "지은이랑 저녁" 20:00 (동석자 "지은")
     ↓ 위치             → 송금 직전 2시간 안에 끝난 연남동 체류 19:12~21:05
     ↓ 사진 내용 인식   → 그 체류 구간의 사진 파스타 · 2인 세팅
OUT  "링키가 찾았어요"
     "이 송금, 연남동에서 지은님과 먹은 파스타 정산 아닌가요?"
     [맞아요]   → 식비 18,000원 재분류 + 사진·일정 연결
     [아니에요] → 단순 이체로 유지
```
> 내 쪽엔 결제 기록이 없으므로 **사진이 유일한 흔적.** 기존 가계부가 '이체'로 버리는 구간.

**④ 패턴 분석 & 미래 예고**
```
IN   누적 지출(내 몫 기준) + 복원된 맥락 + 다음 주 캘린더
OUT  내 지출 패턴 / 다음 주 예고 / 칭찬
```

### 4-5. 확인 레이어 (필수)

모든 추론 결과에 **[맞아요 / 수정]** 버튼 + **추정 근거 노출**
- "입금 3건이 들어왔어요"
- "그 시간 사진에 파스타가 있었어요"

수정 내역은 학습 → 같은 가맹점·같은 친구 다음부터 자동 적용

### 4-6. OUTPUT — 데이터 구조

```
결제/송금 원본 (immutable — 절대 수정하지 않음)
├ 가맹점명 / 금액 / 승인시각 / MCC
└ 복원 레이어 (mutable)
   ├ 장소         연남동 파스타집 · 좌표
   ├ 분류         식비 (송금 → 재분류)
   ├ 내 몫        ← 모든 리포트의 기준값
   ├ 받을/보낼 돈  대기 → 확정
   ├ 연결 기록    사진 / 일정 / 동석자
   └ 신뢰도       자동확정 / 사용자확인 / 미확인
```

| 화면 | 쓰는 데이터 |
|---|---|
| 홈 · 오늘 지출 | 복원 레이어 전부 |
| 오늘의 동선 지도 | 체류 좌표 + 결제 위치 |
| 오늘의 사진 | 사진 ↔ 지출 연결 |
| 정산 대기함 | 받을/보낼 돈 |
| 리포트 | 내 몫 누적 + 다음 주 캘린더 |
| 검색 | 장소 · 사진 · 일정 역색인 |

### 4-7. 프라이버시 (과제 요구사항 f)

| 데이터 | 처리 |
|---|---|
| 위치 | **체류 지점만** 저장, 이동 경로 전체 미저장. 원본 좌표는 기기에만 |
| 사진 | **내용 인식 · 얼굴 검출 전부 온디바이스**, 원본 서버 미전송 |
| 카카오톡 | 읽지 않음 — 돈의 흐름 + 내 사진만 |
| 고지 | 온보딩 + 프로필 `개인정보 & 권한`에 수집항목 · 목적 · 저장위치 명시 |

### 상세

#### UC-01. 지출 내역 가져오기
- **상황**: 설치 직후, 아무 기록도 없음
- **행동 (온보딩 5단계)**
  1. **본인인증 → 닉네임**: 이름·주민등록번호 앞 7자리·통신사·휴대폰 번호 입력, 본인확인 약관(필수) 동의 → 인증번호 6자리 → 닉네임
  2. **서비스 권한 연동**: 카드·계좌(필수), 캘린더·갤러리·위치(선택)를 소스별로 켜고 끔
  3. **개인정보 고지**: 소스별 수집 항목 한 줄 확인. 갤러리는 "결제 시각 ±30분 · 반경 500m 사진만 사용", 하단에 "내 기기 안에 암호화해 저장하고, 서버로 보내지 않아요". 선택 항목은 "동의 안 함" 가능
  4. **결제내역 불러오기**: 금융앱식 약관 동의((필수) 3개 · (선택) 1개) → "동의하고 불러오기"
  5. **시작**: "Linky와 함께 흩어진 지출 맥락을 모아봐요" → Linky 시작하기
- **시스템**: 약관 동의 후 결제내역을 불러오고("결제내역을 불러왔어요"), 맥락 복원은 첫 화면인 홈·캘린더의 결제 카드에서 바로 보인다. 온보딩에서 복원 건수·결과를 따로 보여 주지 않는다
- **결과**: 시작하면 홈으로 진입. 이미 복원된 결제 카드(장소·탑승 지점·근거)를 바로 확인할 수 있다
- **분기**
  - 선택 권한(캘린더·갤러리·위치) 거부 → 해당 소스는 모든 화면의 근거·집계에서 제외, 나머지로 동작. 프로필 > 개인정보 & 권한에서 나중에 다시 켤 수 있음(끌 때는 확인창)
  - 카드·계좌는 필수 연결이라 해제 불가
  - 필수 약관 미동의 → "동의하고 불러오기" 비활성
  - 인증번호 시간 초과(3:00) → 다시 받기
- **쓰지 않는 것**: 연락처 권한(앱에서 사용하지 않음), "기억 안 나던 지출 N건을 채웠어요" 안내 문구

#### UC-02. 오늘 지출 확인
- **진입**: 홈 (기본 탭)
- **시스템**: 주간 캘린더 · 오늘 지출 · 하루 리포트 · 동선 지도 · 오늘의 사진
- **원칙**: 평가 문구 없음 — 사실만

#### UC-03. 결제 장소 복원 ★
- **상황**: "(주)포토이즘코리아 4,000원" — 뭘 썼는지 기억 안 남
- **시스템**: 승인시각이 어느 체류 구간에 속하는지 → 역지오코딩 → 반경 50m POI와 가맹점명 대조 → 사진 EXIF로 교차검증
- **결과**: **포토이즘 강남역점 · 강남역 11번출구** + 그날 사진
- **UI 필수**: 맞아요 / 수정, 추정 근거 명시
- **금지**: 일반 통계·추측으로 빈칸 채우기

#### UC-04. 이동 지점 복원 ★
- **상황**: "카카오모빌리티 12,400원" — 어디서 탔는지 어디에도 안 남음
- **시스템**: 결제시각이 **체류 구간 밖** → 이동 중 판정 → 직전 체류지 = 탑승 지점
- **결과**: **압구정로데오역 2번출구 인근 택시 탑승**
- **가치**: 위치 로그 없으면 절대 복원 불가 — 차별점 증명 케이스

#### UC-05. 그날 동선 보기
- **진입**: 홈 `오늘의 동선 지도`
- **시스템**: 체류 좌표 + 결제 발생 위치를 시간순으로 한 지도에
- **가치**: 금액 → 장소 → 장면으로 기억이 되살아남

#### UC-06. 그날 사진 연결
- **진입**: 홈 `오늘의 사진`
- **시스템**: 촬영시각·GPS로 그날 결제와 자동 매칭
- **보완**: 자동 매칭 실패분은 지출 내역에서 `앨범에서 불러오기`로 수동 연결

#### UC-07. 대표 결제 정산 ★
- **상황**: 내가 대표 결제해서 총 지출이 부풀어 보임
- **시스템**: 결제 후 72h 입금 패턴 + 캘린더 참석자 + 사진 인원으로 인원 추정
- **알림**: "고깃집 12만원, 그룹 지출 같아요" + **근거**("입금 3건이 들어왔어요")
- **결과**: 총 12만원 → **내 몫 3만원 / 받을 돈 9만원**, 월 누계 즉시 재계산
- **보관**: 홈 `정산 대기함` → 완료 시 리포트 `정산 내역`

#### UC-08. 송금 맥락 복원 ★★
- **상황**: 친구가 결제, 내가 송금 — "김지은 18,000원"만 남고 가맹점 정보 없음
- **시스템**: 송금 적요의 이름을 내 일정 동석자 이름과 대조("김지은" ↔ 일정 "지은이랑 저녁"의 동석자 "지은") → 송금 직전 2시간 안에 끝난 위치 체류(연남동 19:12~21:05) → 그 구간 사진의 **내용 인식**(파스타·2인). 연락처는 쓰지 않는다
- **진입**: 홈에 감지 알림 "링키가 찾았어요 · 김지은 18,000원 송금, 연남동 기록과 이어져요" → 탭하면 확인 화면
- **확인 화면**: "이 송금, 연남동에서 지은님과 먹은 파스타 정산 아닌가요?" + 근거 한 줄씩(내 위치 · 내 일정 · 그날 사진) + [아니에요] [맞아요]
- **결과**: [맞아요] → 캘린더 날짜 상세에서 '이체'가 **식비 18,000원**으로 재분류("식비로 재분류"), 사진·일정 연결. 원본 금액은 그대로
- **분기**: [아니에요] → 이체로 유지하고 홈 알림에서 빠짐. 일정·체류·사진 근거가 하나도 없으면 알림을 띄우지 않음. 위치·사진·캘린더 연동을 끄면 그 근거는 빠짐
- **가치**: 기존 가계부가 '이체'로 버리는 구간. 결제 기록이 없으니 **사진이 유일한 흔적**

#### UC-09. 한 달 지출 조망
- **상황**: "이번 달 대체 어디에 다 썼지?"
- **진입**: 캘린더 탭
- **시스템**: 일별 금액 뱃지 + 일정 함께 표시, `한 달 지출액`에 월 누계
- **원칙**: 사실만 ("이번 달 1,204,300원 / 30일 중 26일 지출")

#### UC-10. 하루 되짚기
- **행동**: 캘린더에서 금액 큰 날짜 탭
- **시스템**: `일자별 지출 내역` — 그날 결제 + 복원된 장소·일정·사진
- **분기**: 복원 실패 건 있음 → 수정 유도 / 없음 → 열람만

#### UC-11. 비정형 검색
- **입력 예**: "성수에서 쓴 돈", "지난주 연남동", "지은이랑 간 데"
- **축**: 장소 · 날짜 · 일정 · 사진 · 금액대 · 카테고리
- **위치**: 캘린더 탭 · 홈 양쪽 진입 가능

#### UC-12. 주간 리포트
- **구성**: 이번 주 사실(총액·카테고리·지출일수) + 어디서 썼는지(가맹점·장소 단위) + `내 지출 패턴`("주말에 60% 집중")
- **톤**: 판단 없는 사실 서술형 (단일 톤)
- **주의**: 품목 단위("원피스") 표현 불가 — 복원 범위는 장소까지

#### UC-13. 다음 주 예고 ★
- **시스템**: 누적 패턴 + 다음 주 캘린더 대조
- **문구**: "다음 주 일정이 N건 있어요" + 날짜·시각·제목 (일정에서 가져온 사실만. 식비 평균 같은 금액 비교 문구는 쓰지 않는다)
- **원칙**: 과거를 혼내지 않고 미래를 알려줌 — 회피 심리 방어기제 회피
- **보완**: `칭찬`에서 줄어든 항목 짚어 재방문 동기 제공

#### UC-14. 월간 리포트
- **주기**: 달에 한 번
- **핵심 수치**: 결제 총액 vs **내가 실제로 쓴 돈**(정산 반영 후)
- **부가**: 맥락 복원율, 카테고리 비중, 전월 대비 변화
- **제외**: 예고 블록 없음 (주간 전용)

#### UC-15. 권한·연동 관리
- **진입**: 프로필 `개인정보 & 권한` / `연동 서비스 관리`
- **표기**: 수집 항목 · 목적 · 저장 위치, 소스별 on/off
- **핵심 고지**: 위치는 체류 지점만 · 사진 처리는 온디바이스 · 카톡은 읽지 않음

### 축적 가치 (UC-12~14 공통)

|---|---|---|

## 7. UI 작성 원칙 (어기면 안 됨)

1. **판단 없는 사실부터** — "과했어요" "줄이세요" 같은 평가 문구 금지
2. **과거를 혼내지 말고 미래를 알려줄 것** — 조절 제안은 `다음 주 예고`에서만
3. **AI 추정 화면엔 [맞아요 / 수정] 버튼 필수** + 추정 근거를 항상 함께 노출
4. **입력은 타이핑 대신 자동** — 수동 입력 동선을 기본으로 만들지 말 것
5. **원본 금액은 수정하지 않음** — 복원 레이어로만 표현
6. **품목(옷·화장품 등) 단위 표현 금지** — 복원 범위는 가맹점·장소까지
7. **페르소나별 톤 분기 없음** — 리포트 A/B(서사형/수치형) 분기는 폐기, 전 화면 단일 톤

### 공통 컴포넌트 (우선 제작 권장)
- AI 확인 버튼 세트 (맞아요 / 수정)
- "링키가 찾았어요" 제안 카드 (근거 노출 영역 포함)
