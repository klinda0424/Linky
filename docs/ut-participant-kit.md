# Linky(링키) 사용성 테스트 — 참가자 안내서

> 참가자에게 그대로 전달하는 배포용 자료다. 진행자·분석자용 내용은 `docs/ut-guide.md`에 있다.
> 전달하기 전에 아래 `<제출 방법>`을 채운다. 접속 주소는 UT 모드(`ut/new-flow`, 커밋 `b955df9`) Vercel 배포의 고정 주소로 넣어 두었다. 앱을 고쳐 다시 배포하면 주소가 바뀌므로, 그때는 `docs/ut-guide.md`의 "배포 전 점검"을 거쳐 이 주소를 교체한다.

## 시작하기 전에

- **소요 시간**: 약 20~25분
- **준비물**: 스마트폰(추천) 또는 노트북 브라우저, 인터넷 연결
- **접속 주소**: https://linky-at2odxj8z-klinda0424s-projects.vercel.app/?ut=1
  - 주소 끝의 `?ut=1`이 있어야 앱이 과제를 한 장씩 안내하고 조작 기록을 자동으로 남겨요. 지우지 마세요.
  - 노트북에서 열 때는 브라우저 창을 폰 크기(너비 약 375px)로 맞춰 주세요. 크롬에서 `F12`를 누르고 `Ctrl + Shift + M`으로 기기 모드를 켠 뒤, 크기를 375로 지정하면 쉬워요.
- **앱을 평가하는 자리가 아니에요.** 앱이 쉬운지 확인하는 자리예요. 못 찾거나 헷갈려도 참가자 잘못이 아니니 편하게 해 주세요. 헷갈린 곳이 가장 중요한 정보예요.
- 가능하면 **생각나는 것을 소리 내어 말하면서** 진행하고, 화면을 녹화하거나 메모해 주세요(필수는 아니에요).

## 꼭 지켜 주세요

1. **새로고침(F5, 당겨서 새로고침)을 하면 처음부터 다시 시작돼요.** 중간에 화면이 이상해도 새로고침하기 전에 진행자에게 먼저 알려 주세요.
2. 앱 안의 이름·금액·일정·사진은 전부 **가상의 인물(김소연)의 가짜 데이터**예요. 참가자의 실제 정보는 입력하지 않아요.
3. 본인 인증 화면에는 **아래 가짜 값**을 넣어 주세요.
   - 이름: 김소연 / 주민등록번호 앞 7자리: 000101-4 / 휴대폰: 010-0000-0000 / 인증번호: 아무 6자리 / 닉네임: 아무거나
4. 과제 순서대로 진행해 주세요. 앞 과제에서 한 일이 뒤 과제에 영향을 줘요.
5. 과제마다 3분 안에 끝나지 않으면 "못 끝냈어요"로 적고 다음으로 넘어가도 괜찮아요.
6. 어디를 눌러야 하는지 알려 주지 않아요. "여기 눌러 보면 될까?" 하고 짐작해서 눌러 보세요.

## 과제 카드

아래 상황을 읽고, 앱에서 해 보세요. 끝내면 **자가 기록표**에 바로 적어 주세요.

> 처음에는 로그인 화면(온보딩)이 나와요. 과제 1·2는 그 안에서 해요. 온보딩이 끝나면 홈 화면에서 시작하고, 앱 속 오늘은 **10월 31일**이에요.

| 번호 | 상황 |
|---|---|
| 1 | 사진은 꼭 필요한 것만 쓰게 하고 싶어요. 앱을 시작하면서 설정해 보세요. |
| 2 | 카드 결제내역을 불러오려고 해요. 꼭 필요한 약관에만 동의하고 진행해 보세요. |
| 3 | 오늘(10/31) 낮에 쓴 택시와 포토이즘 결제가 어디서 쓴 건지 확인하고, 맞으면 확인해 주세요. |
| 4 | 오늘 저녁 고깃집은 동기 4명과 먹고 내가 냈어요. 내가 실제로 쓴 돈으로 정리해 주세요. |
| 4-B (선택) | 과제 4를 **끝내기 전에**, 사실 한 명이 못 와서 3명이었다고 가정하고 인원을 바꿔 보세요. 건너뛰어도 돼요. |
| 5 | 어제(10/30) 밤 "김지은 18,000원"을 보냈는데 뭐였는지 기억이 안 나요. 앱에서 확인해 보세요. |
| 6 | 10/30 낮 "(주)샐러디 선릉점"에는 기록이 없어요. 앨범에서 사진을 붙여 보세요. |
| 7 | 오늘 어디를 다녔는지 지도로 보고, 결제 핀을 하나 열어 보세요. |
| 8 | 방금 정산한 고깃집이 정산 내역에서 어떻게 보이는지 확인해 보세요. (과제 4를 끝낸 뒤에만) |
| 9 | 다음 주에 약속이 있는지 확인해 주세요. |
| 10 | 10~11월에 성수에서 쓴 돈을 찾아보세요. |

## 자가 기록표

과제를 끝낼 때마다 한 줄씩 적어 주세요. 정확하지 않아도 괜찮아요.

- **결과**: 끝냈어요 / 못 끝냈어요 / 잘 모르겠어요
- **헤맨 정도**: 바로 했어요 / 조금 헤맸어요 / 많이 헤맸어요
- **쉬웠나요?**: 1(매우 어려워요) ~ 5(매우 쉬워요) — 앱 안 난이도 질문과 같은 방향이에요
- **메모**: 멈췄던 화면, 눌러도 아무 일 없던 곳, 이해가 안 된 문구를 **화면에 쓰여 있는 그대로** 적어 주세요.

## 마치고 답해 주세요

정답은 없어요. 느낀 그대로 짧게 적어 주세요.

1. 결제 옆에 붙은 위치·일정·사진은 무엇이라고 생각했나요?
2. "링키가 찾았어요"에서 보여 준 근거를 보고 어떤 생각이 들었나요?
3. 송금 이름이 "지은이랑 연남동 저녁"으로 바뀐 것을 어떻게 느꼈나요? 바뀐 걸 알아챘나요?
4. 그룹 지출을 정산할 때 화면이 한 장씩 올라오는 방식은 어땠나요? 어느 단계가 가장 헷갈렸나요?
5. 정산 결과의 "결제 총액 → 내가 실제로 쓴 돈"은 무슨 뜻이라고 이해했나요?
6. 지도의 결제 핀은 어디를 가리킨다고 생각했나요?
7. "기록 없음"이라고 적힌 곳을 봤을 때 어떤 느낌이었나요?
8. 사진·위치를 쓰는 범위를 설명한 화면에서 기억나는 게 있나요?
9. 리포트의 "다음 주 예고"는 어떤 도움이 된다고 느꼈나요?
10. 이 앱에서 다시 쓰고 싶은 기능과 쓰고 싶지 않은 기능은요?

## 제출하기

- 위의 **자가 기록표**와 **마치고 답해 주세요**를 `<제출 방법>`으로 보내 주세요.
- 녹화·녹음을 했다면 함께 보내 주세요(선택). 이름 대신 **참가자 번호(P__)** 만 적어 주세요.
- 보내 주신 내용은 이 앱을 개선하는 데에만 쓰고, 팀 공유 폴더 밖으로 내보내지 않아요.

## 문제가 생기면

| 상황 | 이렇게 해 주세요 |
|---|---|
| 앱이 안 열려요 | 주소를 다시 확인하고, 그래도 안 되면 진행자에게 알려 주세요 |
| 화면이 멈췄어요 / 이상해요 | 새로고침하기 **전에** 어떤 화면이었는지 적고 진행자에게 알려 주세요. 새로고침하면 처음(본인 인증)부터 다시 해야 해요 |
| 이미 한 과제를 다시 해야 해요 | 정산·송금 같은 과제는 한 번 하면 알림이 사라져요. 새로고침하면 처음부터 다시 할 수 있어요 |
| 실수로 시트(아래에서 올라온 창)를 닫았어요 | 그대로 적어 두고, 홈 화면에서 알림을 다시 눌러 이어서 진행해 주세요 |
