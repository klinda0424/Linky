## 플로우 공통 규칙

- 근거는 사용자 기록뿐이다: 내 위치(결제 당시), 내 일정(결제 시각이 일정 ±60분 안), 내 사진(결제 ±30분), 입금, 내가 붙인 기록. 근거가 없으면 "기록 없음".
- AI 추정 화면에는 [맞아요 / 수정(아니에요)]과 근거를 함께 보인다. 원본 금액은 수정하지 않고 복원 레이어로만 표현한다.
- 연동을 끈 소스는 모든 화면의 근거·집계에서 빠진다.
- 평가·훈계 톤 금지, 관찰형("~했어요"). 눌러서 갈 곳이 없는 버튼·링크는 두지 않는다.
