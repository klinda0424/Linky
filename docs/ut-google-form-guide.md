# Linky UT 구글폼 활용 가이드

> UT 결과(자가 기록표 · 마치고 답해 주세요 · 앱 기록 파일 2개)를 **구글폼 하나로 모으는 방법**이다.
> 1부는 진행자(팀원)용, 2부는 참가자에게 그대로 보내는 부분이다.
> 폼 내용은 `docs/ut-participant-kit.md`와 같고, 폼은 `docs/ut-google-form.gs`로 자동 생성한다.

---

## 1부. 진행자(팀원)용

### 1. 폼 만들기 (처음 한 번, 약 2분)

1. https://script.google.com → **새 프로젝트**
2. 기본 코드를 지우고 `docs/ut-google-form.gs` 내용을 통째로 붙여넣기 → 저장(`Cmd/Ctrl + S`)
3. 위쪽 함수가 `createLinkyUTForm`인지 확인 → **▶ 실행**
4. 권한 창: **권한 검토 → 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동 → 허용**
   - "Google에서 확인하지 않은 앱" 경고는 직접 만든 스크립트라 뜨는 정상 경고다.
5. 아래 **실행 로그**에 나오는 주소 3개를 팀 채팅에 공유한다.
   - **편집 주소**: 폼 수정용 (팀원만)
   - **참가자용 주소**: 참가자에게 보내는 제출 링크
   - **응답 시트**: 응답이 자동으로 쌓이는 구글 시트

> 스크립트를 **두 번 실행하면 폼이 두 개** 생긴다. 한 명만 한 번 실행한다.

### 2. 만든 직후 확인할 설정

| 위치 | 설정 | 이유 |
|---|---|---|
| 폼 편집 → 설정 → 응답 | **"로그인 필요" 끔**, 이메일 수집 끔 | 참가자가 로그인 없이 제출하고, 개인정보를 받지 않기 위해 |
| 폼 편집 → 오른쪽 위 `⋮` → 공동작업자 추가 | 팀원 초대 | 함께 수정·응답 확인 |
| 응답 시트 → 오른쪽 위 공유 | 팀원만 편집자로 | 결과를 팀 공유 폴더 밖으로 내보내지 않기 위해 |

### 3. 참가자에게 보낼 것

- **앱 주소**: `<UT 배포 주소>/?ut=1` — **모든 참가자에게 같은 링크**를 보내면 된다.
  - `p=` 없이 열면 앱이 참가자 번호(예: P4821)를 자동으로 붙이고, 마지막 "수고하셨어요!" 화면에 크게 보여 준다. 참가자는 그 번호를 폼에 적는다. 기록 파일 이름에도 같은 번호가 들어가 서로 맞춰 볼 수 있다.
  - 번호를 팀이 미리 정하고 싶을 때만(녹화·메모와 맞추기, 대면 진행) `&p=P01`처럼 붙여서 참가자마다 다른 링크를 보낸다.
  - 한 기기를 여러 명이 돌려 쓰는 대면 진행이면 `&share=0`을 붙인다(파일 받기 버튼이 숨는다 → 이 경우 구글폼의 기록 칸은 비워도 된다).
- **참가자 안내서** (`docs/ut-participant-kit.md`) — `<제출 방법>` 자리에 **구글폼 참가자용 주소**를 넣는다.
- 아래 **2부(참가자용 제출 방법)** 를 그대로 복사해 함께 보낸다.

### 4. 응답 확인·분석

1. **응답 시트**에서 참가자 번호(P01 …)별로 한 줄씩 쌓인다.
2. 자가 기록표(결과·헤맨 정도·쉬움)는 과제마다 열이 따로 생겨 바로 정렬·필터할 수 있다.
3. **앱 기록(CSV) 꺼내기**
   - "요약 기록", "상세 기록" 칸의 내용을 복사 → 메모장에 붙여넣고 `ut-summary-P01.csv`처럼 저장 → 엑셀·구글 시트로 열기
   - 또는 새 구글 시트 A1에 붙여넣고 **데이터 → 텍스트를 열로 분할(쉼표)**
   - 참가자가 "두 기록 한 번에 복사하기"로 붙여넣었다면 `[요약 기록 ut-summary]`, `[상세 기록 ut-events]` 제목으로 나뉘어 있다.
4. 요약 CSV 열: `participant, task, attempt, result, duration_s, taps, misses, dead_taps, screens, ease_1to5`
   - 상세 CSV 열: `participant, task, attempt, t_ms, type, detail, at`
5. **주의**: 구글 시트 한 칸에는 약 5만 자까지만 들어간다. 상세 기록이 아주 길면 잘릴 수 있으니, 잘린 응답은 참가자에게 파일을 따로 받거나 "파일·녹화 링크" 칸의 링크로 받는다.

### 5. 자주 생기는 문제

| 상황 | 해결 |
|---|---|
| 참가자가 폼을 못 열어요 | 설정 → 응답 → "로그인 필요"가 꺼져 있는지 확인 |
| 파일 받기 버튼이 안 보여요 | 주소에 `share=0`이 붙어 있는지 확인. 원격 참가자는 `share=0` 없이 보낸다 |
| 파일이 받아지지 않아요(폰 브라우저) | "두 기록 한 번에 복사하기" → 폼의 "요약 기록" 칸에 붙여넣기 |
| 같은 참가자가 두 번 제출했어요 | 응답 시트에서 제출 시각이 늦은 줄을 기준으로 본다 |
| 앱 주소가 바뀌었어요(재배포) | 이미 진행 중인 참가자는 이전 주소로 끝까지, 새 참가자부터 새 주소. 폼은 그대로 쓴다 |

## 2부. 참가자용 제출 방법 (그대로 복사해 보내기)

> **테스트를 마친 뒤, 아래 순서대로 제출해 주세요. 약 5분 걸려요.**
>
> **1. 앱에서 기록 파일 2개 받기**
> - 마지막 과제를 끝내면 "수고하셨어요!" 화면이 나와요.
> - 화면 위쪽의 **"내 참가자 번호"**를 적어 두세요(폼에 적어요).
> - **"1. 요약 파일 받기"**, **"2. 상세 기록 파일 받기"** 를 **둘 다** 눌러 주세요. 받은 버튼에는 ✓ 표시가 생겨요.
> - 파일이 안 받아지면 **"두 기록 한 번에 복사하기"** 를 눌러 주세요.
> - ⚠️ 이 화면에서 **새로고침하거나 창을 닫지 마세요.** 기록이 처음부터 다시 시작될 수 있어요.
>
> **2. 제출 폼 열기**: `<구글폼 참가자용 주소>` (로그인 필요 없어요)
>
> **3. 폼 작성하기**
> - **참가자 번호**: 앱 마지막 화면에 크게 보이는 **"내 참가자 번호"**(예: P4821)를 적어 주세요. 이름·연락처는 적지 않아요.
> - **자가 기록표**: 과제마다 결과 · 헤맨 정도 · 쉬움(1~5)을 골라 주세요. 하지 않은 과제는 비워 두세요.
> - **마치고 답해 주세요**: 느낀 그대로 짧게 적어 주세요. 정답은 없어요.
> - **앱 기록 붙여넣기**: 받은 파일을 메모장(또는 엑셀)으로 열어 **전체 선택 → 복사 → 붙여넣기** 해 주세요.
>   - `ut-summary-P__.csv` → "요약 기록" 칸
>   - `ut-events-P__.csv` → "상세 기록" 칸
>   - "두 기록 한 번에 복사하기"를 썼다면 → "요약 기록" 칸에 통째로 붙여넣기
>   - 너무 길어서 안 들어가면 → 파일을 구글 드라이브 등에 올리고 공유 링크를 "파일·녹화 링크" 칸에 적어 주세요.
>
> **4. 제출** 버튼을 누르면 끝이에요. 참여해 주셔서 감사합니다!
>
> 보내 주신 내용은 이 앱을 개선하는 데에만 쓰고, 팀 공유 폴더 밖으로 내보내지 않아요.
